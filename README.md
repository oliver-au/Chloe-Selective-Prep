# Chloe Selective Prep

This repository contains two skills for making and reviewing NSW selective school preparation videos, along with the source for the Chloe Thinking Studio course.

## Tutorial video skills

- [Create a Chloe tutorial video](skills/create-chloe-tutorial-video/SKILL.md) turns a question or teaching point into a narrated lesson with worked examples and practice. It covers Reading, Mathematical Reasoning, Thinking Skills and Writing.
- [Evaluate a Chloe tutorial video](skills/evaluate-chloe-tutorial-video/SKILL.md) reviews a finished lesson against its learning objectives and checks the reasoning, narration, captions and learner transcript.

To use either skill in Codex, ask Codex to install it from its folder in this repository. Then invoke `$create-chloe-tutorial-video` with a question, or `$evaluate-chloe-tutorial-video` with the lesson objectives and finished materials.

## Chloe Thinking Studio

The course includes 72 Thinking Skills lessons across nine units, two guides and 144 practice and review questions. The [website source and local setup instructions](weibsite/choloe-selective-thinking-skills/) include the course player, editable lessons and reviewed films.
